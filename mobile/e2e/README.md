This directory is reserved for future End-to-End tests using [Detox](https://wix.github.io/Detox/).

## Setup (Not Yet Configured)

When ready to implement E2E tests:

1. Install Detox:
   ```bash
   npm install -D detox @types/detox
   ```

2. Create `.detoxrc.js` in the mobile root

3. Add test files in this directory following the pattern:
   - `login.e2e.ts`
   - `navigation.e2e.ts`
   - `events.e2e.ts`
