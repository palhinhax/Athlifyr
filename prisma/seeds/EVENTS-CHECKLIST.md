### Priority Levels

- **🔴 CRITICAL**: World Marathon Majors, UTMB, Western States, Ironman Kona
- **🟠 HIGH**: USA majors, European trail icons, HYROX majors
- **🟡 MEDIUM**: Regional USA races, international series
- **🟢 LOW**: Niche/cult races, smaller regional events

### Query to Check Existing Events

```sql
-- List all seeded events
SELECT id, slug, region, eventDate
FROM Event
WHERE eventDate >= NOW()
ORDER BY eventDate ASC;

-- Count events by region
SELECT region, COUNT(*) as total
FROM Event
GROUP BY region;
```
